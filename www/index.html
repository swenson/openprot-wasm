OpenPRoT on the Caliptra emulator

This page runs OpenPRoT's VeeR firmware on an emulated Caliptra 2.1 subsystem (the Caliptra core and the MCU), in this browser tab. Each scenario is one of OpenPRoT's test images, with the host's side of the test built into the page.

Images and versions

Image Built from Source version Version it reports

The version an image reports is a number that the build wrote into the image, which Caliptra copies to its CPTRA_FW_REV_ID registers. It can differ from the version of the sources. The MCU ROM and the MCU firmware have no version number.
